# Sprint 0 — Foundation and scope

## Goal
Establish product boundaries, architecture, contracts, and Android project
baseline before feature implementation.

## Deliverables
PRD, TRD, architecture, policy, data dictionary, test strategy, repository
scaffold, contribution rules, Android build baseline, CI, and issue backlog.

## Definition of done
- Docs reviewed for consistency.
- No blocked live-game integration included in MVP.
- Build/test commands documented and reproducible.
- Every issue has scope, acceptance criteria, and dependencies.
