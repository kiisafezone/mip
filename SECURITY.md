# Security Policy

## Supported versions

Security fixes are currently considered for the latest version on the
`main` branch. MIP is an early-stage project and does not currently publish
a formal release support matrix.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, pull requests,
or discussions.

Use GitHub's private vulnerability reporting / Security Advisories for this
repository if the feature is enabled. If private reporting is unavailable,
contact the repository owner through the private contact options on the
GitHub profile: https://github.com/kiisafezone.

Include, when safe to do so:

- A concise description and potential impact.
- Affected commit, version, component, or configuration.
- Minimal reproduction steps in a private report.
- Any mitigations you have identified.

Do not attach real player data, credentials, access tokens, private recordings,
or third-party confidential material. Do not publicly disclose exploit details
before coordinating a fix and disclosure timeline with the maintainer.

## Response

The solo maintainer will acknowledge reports as soon as reasonably possible,
assess severity and reproducibility, and coordinate a fix and disclosure.
No fixed response-time SLA is promised at this stage.
